# CreateJoy Website

This is a static website prototype. Open `index.html` in a browser to view it.

## Project files

- `index.html` contains the page content and section structure.
- `styles.css` contains the page layout, colors, typography, and responsive styles.
- `script.js` contains the navigation, hero slideshow, and scroll reveal behavior.
- `assets/` contains the logo, photos, and video used by the page.

The prototype can later be connected to a domain or hosting service.
